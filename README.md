# 一纸千年 · 心纹研学页

爱菊小学「一纸千年」研学营十楼 **心纹** 站点的 15 分钟互动课投屏网页。

按林正《一纸千年 15 分钟互动课程大纲》实现，纯前端、不联网、不需要服务器：**一个 `dist/index.html` 双击就能放**。

- 课程主线：神秘文字登场 → 回到商代 → 认识象形字 → 汉字演变 → 猜猜乐 → 冷知识 → 配对挑战 → 回到现代 → 弹性备用题
- 授课形态：教师单机投屏，学生举手集体回答，页面由教师操作
- 三批学生连续上课，一键重置即可重来

---

## 一、现场怎么用

1. 拿 `dist/index.html`（已随仓库提交，**不用装任何东西**）。
2. 双击用 Chrome / Edge 打开 → 按 `F` 全屏。
3. 封面点「揭晓答案」→「开启千年之旅」，之后用 `→` 或底部箭头翻页。
4. 三批学生轮换时按 `Shift + R`，答题、配对进度全部清零，回到第一幕。

| 快捷键 | 作用 |
| --- | --- |
| `→` / `空格` | 下一节 |
| `←` | 上一节 |
| `1` – `9` | 直达第 N 节 |
| `P` | 暂停 / 继续动画（讲课时定格画面用） |
| `R` | 重播本节动画 |
| `Shift + R` | 全部重置（换一批学生用） |
| `F` | 全屏 / 退出全屏 |

页面底部有一条半透明教师控制条：翻页、进度圆点、本节计时、暂停、重播、重置、全屏。鼠标移上去才完全显现，投屏时不会抢画面。

> 也可以直接在网址后加 `?stage=5` 直达第五节，用于课前彩排。

## 二、九页与大纲对应

| 页 | 页面标题 | 对应大纲 | 建议时长 |
| --- | --- | --- | --- |
| 1 | 这些符号，是图画还是文字？（含穿越动画） | ① 神秘文字登场 | 1.5 min |
| 2 | 三千多年前，人们这样记事情 | ② 回到商代 · 龟甲兽骨与生活场景 | 1 min |
| 3 | 为什么这些字长得像图画？ | ② 认识象形字（山、日对照实物） | 1 min |
| 4 | 一个字，走过了三千年 | ② 时间轴 + 重点动画（山为主，日补充） | 2 min |
| 5 | 这个字，你认得出来吗？ | ③ 甲骨文猜猜乐（月 / 木 / 田） | 2.5 min |
| 6 | 为什么叫「甲骨文」／他们也关心天气 | ④ 冷知识两页 | 1.5 min |
| 7 | 把它们配成一对 | ⑤ 古文字配对挑战（山日月木） | 2 min |
| 8 | 挑战完成（含时光机返航动画） | ⑥ 回到现代 + 通关徽章 | 0.5 min |
| 9 | 再猜一个：这是什么？ | ⑦ 弹性时间 · 备用猜字题（目） | 弹性 |

交互遵循大纲的两条约束：**不设个人排名**（配对只判对错、不记名次），**不安排学生上台操作**（全部由教师点击，学生举手回答）。

其他按大纲落实的点：

- 字形逐笔「刻」出来的串行动画（`Glyph` 的 `draw` 属性），对应大纲「逐阶段演变动画／答案揭晓动画」。
- 每个内容页都有整幅场景插画（商代村落、山、日、田、月夜、树、龟甲、兽骨、青铜鼎、眼睛、占卜问天），对应大纲「古代生活场景、实物对比图、文物图片放大」。
- 「回到现代」先播时光机返航动画，再出现通关徽章与 **心纹** 项目标识。
- 第 9 页底部写明了它属于弹性环节，三个批次使用相同内容。

## 三、投屏适配

不同教室的投影仪从 4:3（1024×768）到 16:9（1920×1080）都有。页面采用**固定 1600×900 设计画布 + 整幅等比缩放**：

- 任何分辨率下排版完全一致，不会出现文字被裁、卡片重叠
- 4:3 时上下留同色留白，画面居中
- 已验证 1024×768、1366×768、1600×900、1920×1080 四种尺寸

## 四、工程结构与开发

```text
yizi-qiannian/
├── dist/index.html          # 构建产物：单文件、离线、现场直接用
├── index.html
├── vite.config.js           # vite-plugin-singlefile：把 JS/CSS/图片全部内联进 HTML
├── src/
│   ├── App.vue              # 页次调度、穿越动画、键盘、计时、暂停、缩放
│   ├── styles/global.css    # 设计 token：宣纸白 / 古铜金 / 朱红 / 深棕 / 思源宋体
│   ├── data/glyphs.js       # 古文字字形（SVG 线稿）与五体阶段
│   ├── assets/xinwen-logo.png  # 心纹官方标识（构建时内联为 base64）
│   ├── components/
│   │   ├── Glyph.vue        # 字形渲染 + 逐笔书写动画
│   │   ├── SceneArt.vue     # 场景插画（11 种，内联 SVG）
│   │   ├── XinwenLogo.vue   # 心纹标识
│   │   ├── TeacherBar.vue   # 教师控制条
│   │   └── NatureIcon.vue   # 封面龟甲用的小图标
│   └── stages/              # S0 封面 + S1–S8 八页
└── README.md
```

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产出 dist/index.html（单文件）
```

技术栈：Vue 3 + Vite + vite-plugin-singlefile。没有 UI 框架、没有外部字体、没有远程图片——构建产物里唯一的 `http://` 是 SVG 命名空间，**断网也能放**。

视觉按大纲第四节执行：宣纸白、古铜金、朱红、深棕四色为主，大尺寸文字、清晰画面、简洁说明；动画只做缓慢呼吸与书写，不闪烁。

## 五、字形校核（上课前必须做一遍）

页面里的古文字分三类：

1. **手绘 SVG 线稿**：`山 日 月 木 田 目` 的甲骨文，以及 `山 / 日` 的金文、小篆。是按通行字形绘制的**示意线稿**，用于课堂观察与对比，**不是拓片扫描件**。
2. **系统字体渲染**：隶书、楷书阶段直接用文字排（宋体/楷体），不涉及字形绘制。
3. **没有引用的内容**：不直接引用卜辞原文，避免编造。冷知识里「他们会把问题刻在甲骨上」只做情境说明，不展示具体卜辞。若要展示真实卜辞，请从《甲骨文合集》选取具体条目、注明编号后放入。

请课程负责人对照《甲骨文合集》《金文编》《说文解字》把第 1 类过一遍。改法很简单——只改 `src/data/glyphs.js` 里对应字的内联 SVG，全站（时间轴、猜猜乐、配对、备用题）同时生效，然后 `npm run build`。

已知需要留意的点：

- 「山」的甲骨文字形目前是**三峰带底线**的写法，不同著录里峰数有差异，以选定拓片为准。
- 「日」甲骨文中间是一短横还是点，各期不同，现取短横。
- 「月」取月牙内加一竖的常见写法。
- 「目」取横置杏仁形眼眶加瞳孔的常见写法，两端的短斜线是眼角的刻法示意，**这一处最容易画错，请重点核**。
- 金文、小篆为示意，非某件具体器物的摹本。

## 六、内容口径

- 项目名统一为《一纸千年》：页面标题、交付文件名、仓库名全部使用这一个名字。
- 距今约三千三百年（商代晚期），页面不写具体王世，避免争议。
- 大纲写明「不要求背诵字体名称和历史年代」，页面因此只标阶段名与粗略年代，重点放在字形对比。
- 冷知识二用「明天会下雨吗／今年收成好不好／这次出行顺不顺利」这类意译提问，**不是卜辞原文**，讲的时候照页面说即可，不要说成原文。
