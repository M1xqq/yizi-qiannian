# 一字千年 · 心纹探源页

爱菊小学「一纸千年」研学营十楼 **心纹** 站点的 15 分钟互动课投屏网页。

按林正《一字千年 15 分钟互动课程大纲》实现，纯前端、不联网、不需要服务器：**一个 `dist/index.html` 双击就能放**。

- 课程主线：神秘文字登场 → 汉字演变 → 猜猜乐 → 冷知识 → 配对挑战 → 回到现代
- 授课形态：教师单机投屏，学生举手集体回答，页面由教师操作
- 三批学生连续上课，一键重置即可重来

---

## 一、现场怎么用

1. 拿 `dist/index.html`（已随仓库提交，**不用装任何东西**）。
2. 双击用 Chrome / Edge 打开 → 按 `F` 全屏。
3. 点「揭晓答案」→「开启千年之旅」进入课程，之后用 `→` 或右下角箭头翻页。
4. 三批学生轮换时按 `Shift + R`，答题、配对进度全部清零，回到第一幕。

| 快捷键 | 作用 |
| --- | --- |
| `→` / `空格` | 下一节 |
| `←` | 上一节 |
| `1` – `7` | 直达第 N 节 |
| `R` | 重播本节动画 |
| `Shift + R` | 全部重置（换一批学生用） |
| `F` | 全屏 / 退出全屏 |

页面底部有一条半透明教师控制条：翻页、进度圆点、本节计时、重播、重置、全屏。鼠标移上去才完全显现，投屏时不会抢画面。

> 也可以直接在网址后加 `?stage=4` 直达第四节，用于课前彩排。

## 二、七幕与大纲对应

| 幕 | 页面标题 | 对应大纲 | 建议时长 |
| --- | --- | --- | --- |
| 1 | 这些符号，是图画还是文字？ | ① 神秘文字登场 | 1.5 min |
| 2 | 商代人怎么写字？ | ② 回到商代 + 认识象形字 | 2 min |
| 3 | 看「山」怎么变成今天的样子 | ② 汉字演变时间轴 + 重点动画 | 2 min |
| 4 | 这个字，是今天的哪个字？ | ③ 甲骨文猜猜乐（月/木/田） | 2.5 min |
| 5 | 两个小秘密 | ④ 甲骨文冷知识（名称由来 / 占问天气） | 1.5 min |
| 6 | 把它们配成一对 | ⑤ 古文字配对挑战（山日月木） | 2 min |
| 7 | 挑战完成 | ⑥ 回到现代 + 通关徽章 | 0.5 min |

大纲的 ⑦ 弹性 3 分钟不占页面：需要加题时停在第四节重复使用，或回退到任意一幕重讲。

交互遵循大纲的两条约束：**不设个人排名**（配对只判对错、不记名次），**不安排学生上台操作**（全部由教师点击，学生举手回答）。

## 三、投屏适配

不同教室的投影仪从 4:3（1024×768）到 16:9（1920×1080）都有。页面采用**固定 1600×900 设计画布 + 整幅等比缩放**：

- 任何分辨率下排版完全一致，不会出现文字被裁、卡片重叠
- 4:3 时上下留同色留白，画面居中
- 已经验证过 1024×768、1366×768、1600×900、1920×1080 四种尺寸

## 四、工程结构与开发

```text
xinwen-tanyuan/
├── dist/index.html          # 构建产物：单文件、离线、现场直接用
├── index.html
├── vite.config.js           # vite-plugin-singlefile：把 JS/CSS 全部内联进 HTML
├── src/
│   ├── App.vue              # 幕次调度、穿越动画、键盘、计时、缩放
│   ├── styles/global.css    # 心纹设计 token（宣纸底 / 朱砂 / 思源宋体）
│   ├── data/glyphs.js       # 古文字字形（SVG 线稿）与五体阶段
│   ├── data/quiz.js         # 猜猜乐题库与配对题
│   ├── components/          # Glyph / NatureIcon / StageFrame / TeacherBar
│   └── stages/              # S0–S6 共七幕
└── README.md
```

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产出 dist/index.html（单文件）
```

技术栈：Vue 3 + Vite + vite-plugin-singlefile。没有 UI 框架、没有外部字体、没有远程图片——构建产物里唯一的 `http://` 是 SVG 命名空间，**断网也能放**。

视觉沿用 `ui(2).md` 的心纹设计系统：宣纸底 `#F8F6F2`、朱砂 `#B73F42`、五行色、思源宋体与克制留白；投屏场景下把字号整体放大到教室可读。

## 五、字形校核（上课前必须做一遍）

页面里的古文字分三类：

1. **手绘 SVG 线稿**：`山 日 月 木 田` 的甲骨文，以及 `山 / 日` 的金文、小篆。是按通行字形绘制的**示意线稿**，用于课堂观察与对比，**不是拓片扫描件**。
2. **系统字体渲染**：隶书、楷书阶段直接用文字排（宋体/楷体），不涉及字形绘制。
3. **没有引用的内容**：不直接引用卜辞原文，避免编造。若要展示真实卜辞，请从《甲骨文合集》选取具体条目、注明编号后放入。

请课程负责人对照《甲骨文合集》《金文编》《说文解字》把第 1 类过一遍。改法很简单——只改 `src/data/glyphs.js` 里对应字的内联 SVG，全站（时间轴、猜猜乐、配对、封面龟甲）同时生效，然后 `npm run build`。

已知需要留意的点：

- 「山」的甲骨文字形目前是**三峰带底线**的写法，不同著录里峰数有差异，以选定拓片为准。
- 「日」甲骨文中间是一短横还是点，各期不同，现取短横。
- 「月」取月牙内加一竖的常见写法。
- 金文、小篆为示意，非某件具体器物的摹本。

## 六、内容口径

- 课名《一字千年》，研学营名《一纸千年》，两者不要混用。
- 距今约三千三百年（商代晚期），页面不写具体王世，避免争议。
- 封面「一九三六年 · 安阳殷墟」指殷墟第十三次发掘（YH127 甲骨坑），作为氛围文案使用；若要更严谨可改为「一八九九年 · 甲骨文被发现」。
- 大纲写明「不要求背诵字体名称和历史年代」，页面因此只标阶段名与粗略年代，重点放在字形对比。
